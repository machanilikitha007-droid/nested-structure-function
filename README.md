# Nested Structure with Function Parameter

## Author
M.Likitha

## Description
This program demonstrates passing a structure containing
another structure to a function.

The Meeting structure contains a nested Time structure.
The complete Meeting structure is passed to a function
for displaying its details.

## Concepts Used
- Structure
- Nested structure
- Function parameters
- Passing structure to a function
- Nested member access

## How to Run

gcc nested_structure_function.c -o nested_structure_function

./nested_structure_function

## Sample Output

Meeting: Project Discussion
Start Time: 10:30
